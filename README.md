# STM32 红外循迹智能车

基于 STM32F10x 的智能小车控制代码，包含红外传感器、电机 PWM、按键、LED 和串口等模块。项目用于红外循迹及嵌入式开发实践，与 [TC264 极速越野智能车](https://gitee.com/kjdz0905/tc264-offroad-car) 是两个不同项目。

## 我的职责

- 参与主控程序的模块化开发与功能集成。
- 负责红外传感器底层驱动，配置 GPIO 上拉输入模式。
- 根据左右红外传感器状态实现停止、直行、左转和右转判断，并配合电机 PWM 与 LED 完成功能联调。

## 代码内容

- `using/main.c`：系统初始化、按键和红外传感器状态读取、主循环循迹逻辑。
- `using/control.c`：左右电机方向与 PWM 控制。
- `hardware/CGQ.c`：红外传感器 GPIO 初始化。
- `hardware/motor.c`：电机驱动相关代码。
- `using/timer.c`、`using/usart.c`：定时器、PWM 和串口基础模块。
- `hardware/` 和 `using/` 为主要业务源码；`Libraries/`、`DebugConfig/`、`Listings/`、`Objects/` 保留了旧工程依赖、调试配置与构建产物。

主循环根据左右红外传感器组合状态选择停止、直行或转向。实际电平含义和转向效果受传感器安装方向、电机接线影响，烧录前需在实车上校准。

## 硬件与复现说明

项目记录中的主控型号为 STM32F103RBT6，但仓库保留的旧 Keil 调试配置标注了 STM32F103CB。当前源码使用 STM32F10x 通用外设接口，单凭代码无法确认实物型号；复现前请核对开发板、启动文件、引脚映射与工程配置。GitHub 仓库也没有完整的可直接打开编译的 Keil 工程文件，不应视为“一键烧录”项目。

首次测试请架起车轮，确认左右电机方向与 PWM 范围；随后校准红外传感器高度、阈值及现场光照。
